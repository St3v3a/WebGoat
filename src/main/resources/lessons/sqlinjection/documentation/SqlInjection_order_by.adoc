The server inventory now accepts only its six named sort columns. You can
sort by ID, hostname, IP, MAC, status or description. SQL expressions and
unknown columns are rejected before a database query runs.

Click "Try an unsupported sort expression" and observe the rejection. Then
sort the list by one of its named columns. Select that same column in the
form to complete the mitigation exercise. The list still omits servers marked
out of order.

Earlier versions allowed an expression in ORDER BY to infer a hidden server's
address. Accepting only known column names closes that injection boundary.
